# Security Policy

## Supported versions

Until the first public release is published, security fixes are developed on the active development branch. After releases begin, this section will list the versions that receive security updates.

## Reporting a vulnerability

Please do **not** report suspected vulnerabilities in a public GitHub issue.

Instead, contact the repository maintainer through the contact options on the [GitHub profile](https://github.com/thisisvista) and include:

- A concise description of the issue and its potential impact.
- The affected version, platform, and relevant component.
- Reproduction steps or a proof of concept, where safe to share.
- Any suggested mitigation.

Please allow reasonable time for investigation and a fix before publicly disclosing the issue. Do not include passwords, account credentials, session tokens, private configuration files, or personal data in a report unless the maintainer has provided a secure way to exchange them.

## Security notes

- Install release files only from this repository's official GitHub Releases.
- Do not install debug or unofficially re-signed APKs as updates to an official installation.
- Keep your operating system and the app up to date.
