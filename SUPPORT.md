# Support

For help with Vista VPN, please use the repository's [GitHub Issues](https://github.com/thisisvista/vista-vpn/issues).

Before opening an issue:

1. Check whether the problem is already reported.
2. Confirm the app version and your operating system version.
3. Describe what you expected and what happened instead.
4. Include clear steps to reproduce the issue.
5. If relevant, attach a screenshot with personal information hidden.

## Logs and private information

VPN logs and configuration files may contain account identifiers, server details, IP addresses, tokens, or other sensitive information. Review and redact them before sharing. Never post passwords, authentication tokens, account backups, private keys, or complete configuration/data folders in a public issue.

## What to include

- Vista VPN version (for Android, see About or the app information screen).
- Device model and Android version, or desktop OS and version.
- Whether the issue occurs on every network or only one.
- The selected server/location and the approximate time of the issue.
- Steps that reliably reproduce the problem.

Please be respectful and keep one distinct problem per issue where practical.
